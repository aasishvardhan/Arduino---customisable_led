# Arduino Customisable LED

An Arduino project that uses an IR remote to control an RGB LED. The remote can be used to turn the LED on/off, select different colors, and adjust the brightness.

## Features

* IR remote control
* RGB LED color selection
* 7 color options
* Adjustable brightness
* LED on/off control

## Components

* Arduino board
* RGB LED
* IR receiver
* IR remote
* 3 × current-limiting resistors
* Jumper wires
* Breadboard

## Color Controls

| Remote Button       | Function            |
| ------------------- | ------------------- |
| `1`                 | Red                 |
| `2`                 | Green               |
| `3`                 | Blue                |
| `4`                 | Yellow              |
| `5`                 | Cyan                |
| `6`                 | Magenta             |
| `0`                 | Not used            |
| Power/ON-OFF button | Toggle LED          |
| `▲`                 | Increase brightness |
| `▼`                 | Decrease brightness |

## Pin Configuration

| Component       | Arduino Pin |
| --------------- | ----------- |
| IR Receiver     | D3          |
| RGB LED - Red   | D11         |
| RGB LED - Green | D10         |
| RGB LED - Blue  | D9          |

The RGB LED channels use PWM pins to control brightness.

## Required Library

This project uses the **IRremote** Arduino library.

Install it through the Arduino IDE Library Manager:

`IRremote`

## How It Works

The IR receiver detects signals from the remote and the Arduino decodes the received IR data.

Each remote button has a corresponding hexadecimal IR code. The program maps these codes to commands such as selecting a color, switching the LED on/off, or changing the brightness.

The selected color is then generated by controlling the three RGB channels using `analogWrite()`.
